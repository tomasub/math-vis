# 2.1 Dimension theorem as a split of the input space

**Built:** `js/viz/dimension-split.js` (model + view), `tests/viz/2.1.test.js` (8 tests), manifest status → `ready`.

- Two stages: input ℝⁿ (N(A) shaded in `q1` with v-arrows, complement N(A)⊥ in `q2` with w-arrows) and output ℝᵐ (R(A) shaded, images Aw drawn in `q2`).
- Animation (Player, t∈[0,1]): the v-vectors shrink to **0** by factor (1−t) and the images t·Aw grow. Everything comes from `splitInputSpace` and `applyRows`, nothing is scripted. The panel shows max ‖Av‖ over a basis of N(A) and whether the complement images are independent (both computed).
- SplitBar: dim R(A) + dim N(A) = n in a fixed-length bar, plus the TeX line.
- Controls: m, n ∈ 1…3, matrix entries (MatrixEditor), rank slider 0…min(m,n) (random matrix of exactly that rank via `randomRankMatrix`), "New random, same rank", Reset, Play/scrub.
- "Fixed by system" panel: complement = N(A)⊥ with the note that any complement works, tol, basis length, axes.
- Default: 3×3 rank 2, A = [1 2 3; 0 1 1; 1 3 4], N(A) = span[−1,−1,1]ᵀ. Inside [−3,3].
