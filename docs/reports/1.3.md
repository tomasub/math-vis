# 1.3 One subspace, two bases

**Built** (`js/viz/two-bases.js`, `tests/viz/1.3.test.js`, manifest status → ready):
- 3D stage with the plane R(A) (A from Example 1.1.1) and two coordinate grids on it (columns of A in `q1`, w₁/w₂ in `q3`), each with its own toggle. Arrows show a₁, a₂, w₁, w₂, and dashed tip-to-tail segments show z₁a₁ + z₂a₂ and x₁w₁ + x₂w₂.
- Draggable y. The drag is orthogonally projected onto R(A) with `coordsInBasis` (the exact 3×2 solve), so y never leaves the plane. The arrow keys use the stage's nudge and go through the same projection. z₁ and z₂ sliders give a non-drag alternative.
- Panels:
  - Coordinates: y = Az, z, x, the conversion x = Mz computed from W, and the notes' x₁ = z₁ + z₂, x₂ = −z₂ when W is the default.
  - Edit W: MatrixEditor, 3×2.
  - Warning: shown if w₁ and w₂ are dependent or leave R(A).
  - Check yourself: PredictReveal.
  - Fixed by system: includes tol.
- If W is not a basis of R(A), x shows "undefined" with the reason and the W grid and plane are not drawn.

**Defaults:** z = (0.5, 0.5), so y = (1, −0.5, 2) is inside [−3, 3]³. `setZ` rescales z so that y stays inside the box.
